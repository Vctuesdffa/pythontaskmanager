# Python Task Manager (Консольный менеджер задач)

## Описание
**Python Task Manager** — это консольное приложение на языке Python, предназначенное для учёта, контроля и организации текущих учебных и рабочих задач. Программа решает проблему потери важных поручений и позволяет управлять списком дел через интерфейс командной строки.

## Возможности
- Добавление новых задач с автоматическим присвоением уникального идентификатора (`add_task`).
- Просмотр полного списка задач с визуальной индикацией статуса (`list_tasks`).
- Отметка выбранной задачи как выполненной (`complete_task`).
- Удаление неактуальных задач по идентификатору (`delete_task`).
- Валидация корректности и длины названия задачи (`validate_task_title`).
- Поиск задач по ключевому слову с учётом и без учёта регистра (`search_tasks`, `search_tasks_case_insensitive`).
- Подсчёт сводной статистики по задачам (`get_task_stats`).

## Технологии
1. **Python 3** — основной язык разработки.
2. **Git** — распределённая система контроля версий.
3. **GitHub** — хостинг репозитория, управление Pull Request и защита веток.
4. **Pytest** — фреймворк для запуска модульных тестов.
